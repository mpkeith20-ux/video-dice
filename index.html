Drop in files from your Session File Backups folders and this tool estimates worked time by measuring the time span of backup saves.

How this estimate works
  • Backups are grouped by project and calendar day.
  • Within each day, backups are split into separate work sessions when the gap exceeds your idle threshold.
  • Each session contributes from first backup timestamp to last backup timestamp.
  • This is an estimate — manually saved backups or disabled autosave can reduce accuracy.
